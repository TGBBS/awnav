Google Search Console 在哪里提交 sitemap.xml

这篇文章说明 sitemap.xml 在 Search Console 里的具体提交流程，以及提交后要关注哪些状态。

2026-07-26
  • 提交入口
  • 填写地址
  • 看状态
  • 常见误区

提交入口

进入 Google Search Console，选择已经验证过的站点属性，然后在左侧菜单里找到 “Sitemaps”。

填写地址

如果站点主域是 https://awnav.com/，常见提交地址就是：

https://awnav.com/sitemap.xml

看状态

提交后重点看三件事：是否成功抓取、是否有 URL 被发现、是否存在页面被排除。

常见误区

提交了 sitemap 不是马上收录。更关键的是页面质量、内链、抓取可达性和内容是否真的有搜索价值。
